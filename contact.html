문의 및 베타 대기 신청

현재 별도의 고객센터 이메일과 자동 결제 시스템을 운영하지 않아 GitHub 공개 양식으로 1차 대기 신청만 받습니다. 이 단계에서는 결제가 진행되지 않습니다.

수익성 진단 베타 대기 신청

GitHub 로그인이 필요합니다. 브랜드 단계, 상품 수, 판매 채널과 해결하고 싶은 문제만 접수하세요. 신청 후에는 해당 GitHub 이슈의 답글 알림을 확인해야 합니다.

상품 10개 진단

상품별 손익, 가격·할인 위험과 핵심 개선안을 정리하는 베타 서비스입니다. 예정 베타가 49,000원.

브랜드 수익 진단

최대 30개 상품, 광고·플랫폼·재고 우선순위와 30일 실행안을 제공하는 베타 서비스입니다. 예정 베타가 99,000원.

중요

공개 신청 단계에서는 실제 매출표·원가표·연락처·고객정보를 받지 않습니다. 비공개 데이터 전달과 결제 절차가 준비되기 전에는 분석 작업이나 결제가 시작되지 않습니다.
